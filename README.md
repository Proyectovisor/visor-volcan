# Visor de datos para la gestión del riesgo de desastres – Volcán, Jujuy (RA)

Visor web de información geoespacial (QGIS + qgis2web / OpenLayers) construido como apoyo a un sistema de alerta temprana a partir del evento hidrometeorológico extremo del 10-01-2017.

Fuentes: datos abiertos WFS de IDEJuy, SIGAM-SEGEMAR, IGN, OpenStreetMap y capas de elaboración propia.
